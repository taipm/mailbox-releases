# MailBox — bản phát hành

MailBox cho macOS: đọc thư Exchange/IMAP từ Mail.app vào kho SQLite trên máy, dán nhãn và tóm tắt thư bằng model AI chạy ngay trên máy (Ollama), không gửi nội dung thư lên cloud.

Kho này chỉ chứa bản phát hành đã ký Developer ID và notarize (DMG) cùng `latest.json` cho tính năng tự cập nhật. Mã nguồn ở kho riêng.

Cài: tải `MailBox-<phiên bản>.dmg` ở mục Releases, kéo MailBox vào Applications. Cập nhật: `mailbox update`.
